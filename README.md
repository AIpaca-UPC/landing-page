# Rumbo — Landing Page

Landing Page de **Rumbo** para el curso **1ASI0730 Aplicaciones Web** (NRC 8137, ciclo 2026-20).

Para AV1 se implementará y desplegará la primera versión del Landing Page utilizando **HTML5, CSS3 y JavaScript**, con diseño responsive.

## Ramas

- `main`: versión estable.
- `develop`: integración del trabajo del equipo.
- `feature/*`: desarrollo de funcionalidades o secciones del Landing Page.
