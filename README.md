# Rumbo — Landing Page

Landing Page del producto **Rumbo**, desarrollado por la startup **AIpaca** para el curso **1ASI0730 Aplicaciones Web** (NRC 8137, ciclo 2026-20).

Rumbo busca mejorar la coordinación del transporte escolar entre padres o tutores y conductores, centralizando el estado de la ruta, hitos relevantes, retrasos e incidencias.

## Alcance AV1

Para AV1 debe existir una primera versión de la Landing Page implementada y desplegada. Este repositorio contiene exclusivamente la experiencia pública de presentación del producto.

## Tecnología

- JavaScript
- Diseño responsive

## GitFlow

- `main`: versión estable/desplegable.
- `develop`: integración.
- `feature/...`: cambios de funcionalidad o sección.

Los cambios deben llegar a `develop` mediante Pull Request. Para la entrega, `develop` se integra en `main`.
