# Guía de contribución — Rumbo Landing Page

## Flujo

1. Partir de `develop`.
2. Crear una rama `feature/<descripcion>`.
3. Implementar una unidad coherente de trabajo.
4. Usar Conventional Commits.
5. Abrir Pull Request hacia `develop`.
6. Revisar visualmente responsive, navegación y contenido antes del merge.

## Commits sugeridos

- `feat(hero): add main value proposition`
- `feat(navigation): add responsive navbar`
- `feat(sections): add product benefits`
- `feat(i18n): add language resources`
- `docs(legal): add privacy policy`
- `fix(responsive): correct mobile spacing`

No subir archivos temporales, builds locales ni configuraciones de IDE.
